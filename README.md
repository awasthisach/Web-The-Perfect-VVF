# Drive Organizer Web

Offline-first Google Drive organizer (React + Vite + Dexie + Drive API).

## Deploy (Vercel)

- **Install:** `npm install --legacy-peer-deps`
- **Build:** `npm run build`
- **Output:** `dist`
- **Node:** 20.x (not 24)

## Local

```bash
npm install
npm run dev
```

Open http://localhost:3000 — use **Test with Demo Token** or **Sign in with Google**.
